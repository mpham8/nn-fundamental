`nn-torchless` is a basic, library-free two-layer neural network [input (784) → hidden (64) → output (10)] trained using mini-batch SGD with the Adam optimizer, with inference implemented in C++. The accompanying write-up, ["Math and Implementation of a Neural Network from Scratch"](https://mpham8.github.io/post.html?slug=basic-nn), explains the underlying math and walks through its corresponding implementation.

`transformer` is a basic Transformer encoder architecture based on Vaswani et al.'s ["Attention Is All You Need"](https://arxiv.org/abs/1706.03762).
